# Compatibility adapters in Mint v1

The bundled compatibility adapters belong to the v1 controller. Consumers
still using them can pin [Mint v1.1.3](https://github.com/jamesonstone/mint/releases/tag/v1.1.3)
and follow the [versioned adapter reference](https://github.com/jamesonstone/mint/blob/v1.1.3/docs/references/compatibility-adapters.md).
For v2, use the [repository-owned workflow](../../website/content/environments.md).
